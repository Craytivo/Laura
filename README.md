# RU Sugaring

Frontend for RU Sugaring, a private home-based sugaring studio in Edmonton.

## Run locally

npm install
npm run dev

## Current frontend scope

- Black-and-white visual system
- Responsive landing page
- Brazilian service as the primary conversion point
- Services and bundles
- Loyalty program
- FAQ
- Booking and gift-card CTAs
- Photography placeholders ready to be replaced with client assets

Booking URL, gift-card destination, final policies, testimonials, logo and photography are intentionally left configurable until the client supplies them.
